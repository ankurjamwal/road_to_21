Pull your runs straight from Garmin's Personal API

This page never asks for your Garmin key and never contacts Garmin, so there is nothing here to leak. A short script on your own computer makes the call and saves a file. You then add that file above. The key stays in your PowerShell window and is never written to disk.

  1. In Garmin Connect on the web, create a Personal API key. Garmin shows it once.
  2. Save the script below as fetch_garmin.py.
  3. In PowerShell, set the key for this window only: $env:GARMIN_PERSONAL_API_KEY = Read-Host "Garmin key"
  4. First run python fetch_garmin.py probe. It prints only field names and status codes, never your values, and shows what Garmin offers.
  5. Then run python fetch_garmin.py to save your runs, with route, per-km laps and weather for the newest 30. Add a start date to limit it, for example python fetch_garmin.py 2026-01-01, or --details 10 for fewer routes.
  6. Add the new garmin_runs.json file above.

The script also saves each recent run's route, per-kilometre laps and start-time weather. The route and weather fill the Share card, and the laps fill Run detail. The weather comes from Open-Meteo, a free service, and the lookup sends only the run's start coordinates and date. Add --no-weather to skip it. If a file is not recognised, the page lists the fields it found.
